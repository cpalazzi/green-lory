# Supported Helper Scripts

Only the scripts listed here are part of the supported human workflow.

## `fetch_travel_time.py`

Builds `data/travel_time_by_cell.csv` by querying the MAP/Oxford Accessibility to Cities 2015 dataset in Google Earth Engine for each onshore 1 degree cell in `data/max_capacities.csv`.

Requirements:
- authenticated Google Earth Engine access
- `data/max_capacities.csv` already generated by `notebooks/01_max_capacities.ipynb`

Typical usage:

```bash
python scripts/fetch_travel_time.py
```

## `merge_global_results.py`

Merges quadrant outputs such as `results/way-2050-spatial-east1/run_global_*.csv` into one canonical scenario CSV, deduplicates by `(latitude, longitude)`, and validates required land/gridless columns.

Typical usage:

```bash
python scripts/merge_global_results.py way-2050-spatial \
  --output results/way_2050_spatial/global_run_results_1h_2050.csv
```

Useful options:
- `--results-dir` to point at a different results root
- `--allow-missing-quadrants` to merge partial runs intentionally
- `--required-column` to enforce extra schema checks

## Policy

All other files under `scripts/` are treated as local diagnostics, scratch helpers, or Copilot convenience tools. They are intentionally excluded from the supported interface and remain gitignored.
